Entry grid

Where a sales exec works. Every template column for the selected genre, with the calculated ones view only. Each exec sees their own clients and nothing else.

Switch genre, switch the view, click a cell to edit it, click an amber dot for that cell's history, open a row chevron for the full record.
Wireframe. Figures are sample data from the current working file, shown so the layout can be judged — not a production system.
